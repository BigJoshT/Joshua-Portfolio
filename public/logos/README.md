## Replacing a logo

Keep the same filename. The ideal file is:
- **256 × 256 px** WebP (or PNG), mark centred and filling about 70% of the frame
- under ~20 KB. Convert at squoosh.app → WebP, quality ~80.

Drop it in and overwrite the old file. It's used in three places
automatically: the 3D orbit, the still orbit for reduced motion, and the
list beside the orbit.

Third-party trademarks, used descriptively. Don't restyle them or imply
endorsement.
